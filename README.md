BMW Sales Performance Dashboard (2010–2024)

Overview
- This project analyzes BMW automobile sales data from 2010 to 2024 using Power BI.
- The dashboard focuses on sales performance, pricing trends, and regional insights to support business decision-making.

Dataset
- BMW sales dataset (2010–2024)

Key fields include model, year, region, fuel type, transmission, price, mileage, and sales volume

Tools
- Power BI
- Microsoft Excel (data preparation)

Key Metrics
- Total Revenue (USD)
- Total Sales Volume
- Average Price (USD)
- Average Mileage (KM)

Dashboard Highlights
- Analyzed revenue trends over time to identify growth patterns
- Identified top-performing BMW models based on sales volume

Compared regional revenue performance across global markets

Explored the relationship between vehicle price and mileage by model
